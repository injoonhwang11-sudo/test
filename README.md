# 셋업 노트

트레이딩 진입 전 조건을 평가하고, 실제 매매 결과를 기록해 등급별 성과를 확인하는 한국어 웹앱입니다. 어두운 테마와 PC·모바일 화면을 지원합니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다. 현재 환경에서는 Node.js 24로 검증했습니다.

```bash
cd /workspace/test
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

개발 서버는 5173 포트에서 실행됩니다. 서버가 출력하는 주소를 브라우저에서 열어 사용합니다. 같은 브라우저와 같은 주소(포트 포함)를 계속 사용해야 동일한 저장 데이터가 보입니다.

```bash
npm test       # 점수·등급·통계·백업 검증
npm run build # 정적 배포 파일을 dist/에 생성
npm run preview -- --port 4173 # 빌드 결과 확인
```

## 사용 순서

1. **체크리스트 설정**에서 샘플 매매법을 수정하거나 새 매매법을 추가합니다. 조건 이름, 배점, 필수 여부와 A+ / A / B 기준을 입력하고 **설정 저장**을 누릅니다. 샘플 표시도 해제할 수 있습니다.
2. **진입 전 평가**에서 종목, 매수·매도, 매매법을 선택합니다. 조건을 체크하면 점수·등급·미충족 조건이 즉시 표시됩니다. 메모를 작성하고 **평가 기록 저장**을 누릅니다. PASS 평가도 저장할 수 있습니다.
3. **평가 기록**에서 실제 거래가 끝나면 R 결과를 입력하고 **결과 저장**을 누릅니다. 예를 들어 -1은 계획한 리스크의 1배 손실, 2.5는 2.5배 이익입니다. 거래하지 않았다면 상태를 **미진입**으로 바꿉니다. 아직 결과가 없으면 **결과 대기**로 둡니다.
4. **성과 분석**에서 등급별 완료 거래 수, 승률, 평균 R을 확인합니다.
5. **JSON 내보내기**로 백업합니다. 모바일에서는 상단의 **내보내기 / 가져오기**를 사용합니다. 가져오기는 현재 데이터를 교체하며, 유효성 검사와 확인 절차를 거칩니다. 먼저 기존 데이터를 내보내세요.

## 판정·통계 기준

- 점수 = 체크한 항목의 배점 합계 ÷ 전체 배점 합계 × 100. 필수 항목도 배점에 포함됩니다. 필수 조건을 모두 체크해도 가산점이 부족하면 PASS일 수 있습니다.
- **필수 조건 하나라도 미충족이면 점수와 관계없이 PASS**입니다.
- 기본 기준: A+ ≥ 90, A ≥ 80, B ≥ 70, 나머지 PASS. 기준은 `100 ≥ A+ > A > B > 0`을 만족해야 합니다. 배점은 0 이상, 배점 합계는 0보다 커야 합니다.
- 등급 판정에는 반올림 전 점수를 사용합니다. 화면 점수는 소수점 한 자리까지 표시합니다.
- 승률 = 0R 초과 거래 수 ÷ 완료 거래 수. 0R도 완료 거래에 포함됩니다.
- 결과 대기와 미진입은 승률·평균 R 계산에서 제외합니다. 거래가 없으면 0 대신 대시를 표시합니다.
- 평가 저장 당시의 조건·배점·점수·등급·매매법 이름을 보존합니다. 설정을 변경해도 과거 기록을 다시 채점하지 않습니다. 통계에는 모든 매매법과 변경 전후 기준의 기록이 함께 포함됩니다.
- 등급은 **조건 충족도**이며 승률이나 수익을 예측하지 않습니다. 예시 조건은 확정된 매매법이 아닌 편집 가능한 샘플입니다.

## 저장과 백업

계정이나 데이터베이스 없이 브라우저의 `localStorage`에 설정과 평가 기록을 저장합니다. 브라우저를 닫아도 유지되지만, 사이트 데이터 삭제·시크릿 모드 종료·기기 변경 시 사라지거나 이어지지 않을 수 있으므로 JSON으로 정기 백업하세요. 기기 간 자동 동기화는 제공하지 않습니다. 작성 중인 미저장 평가는 새로고침 시 초기화됩니다.

JSON은 버전 1 형식만 지원하며, 최대 10MB까지 가져올 수 있습니다. 잘못된 형식·중복 ID·유효하지 않은 등급 기준은 거부합니다. 초기 저장 데이터를 읽지 못한 경우 자동으로 덮어쓰지 않고 알립니다. 글꼴은 Google Fonts를 사용하며 연결되지 않아도 시스템 글꼴로 실행됩니다.

## 검증

- `npm test`: 필수 조건 우선 판정, 등급 경계값, 100점 환산, 미진입·대기 제외, 0R 처리, JSON 유효성 검사.
- Chromium에서 실제 클릭으로 평가 저장, 결과 입력, 재접속 데이터 유지, 통계, 설정 변경 후 과거 기록 보존, 미진입 전환, JSON 왕복을 확인했습니다.
- 390px 모바일 화면에서 네 화면의 가로 넘침과 백업 버튼 노출을 확인했습니다.

## 설치 없이 크롬에서 사용

`setup-note.html`을 내려받아 같은 위치에 보관하고 크롬으로 열면 됩니다. Node.js, 서버, 인터넷 연결 없이 사용할 수 있도록 코드와 스타일을 한 파일에 담았습니다. 원본 변경 후 `node scripts/standalone.js`로 다시 생성합니다.

파일로 직접 실행할 때의 브라우저 저장 동작은 브라우저 정책에 따라 다를 수 있습니다. 파일 이름이나 위치를 바꾸면 저장 기록이 보이지 않을 수 있으므로 옮기기 전 JSON으로 내보내세요. 관리 정책이 로컬 HTML 실행을 차단하는 PC에서는 실행할 수 없습니다.

## Windows 포터블 패키지

`SetupNote-Windows.zip`을 모두 압축 푼 뒤 `실행.cmd`를 더블클릭합니다. Chrome이 표준 위치에 설치되어 있으면 Chrome으로, 찾지 못하면 기본 브라우저로 앱을 엽니다. HTML과 CMD 실행 도우미를 묶은 패키지이며, 네이티브 EXE 설치 프로그램이 아닙니다. Windows에서 실행 도우미를 직접 실행하는 검증은 이 Linux 환경에서 수행하지 못했습니다.

패키지 재생성: `python3 scripts/package-windows.py` (Node.js와 Python 3 필요, 사용자 실행에는 불필요).
